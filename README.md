# 实用系统编程（C/C++/Rust）
- 掌握在Linux/Unix系统使用C/C++/Rust语言实现系统级项目的能力。

## 课程目标
- 构建可靠稳定的系统
- 熟悉端到端的系统设计
- 掌握性能分析，调试和优化底层代码的能力
- 理解内存，磁盘的资源管理方式
- 提高对各种需求的实际编程能力

## 优势
- ICS/OS/CA讲过的高频知识我们会再讲。
- ICS/OS/CA没讲过的工程实践我们会讲。
- 系统方向学术界和企业中用到的前沿知识会略作涉及。
- 减少大学课堂和互联网企业系统编程技术上的GAP。

## 就业价值
- 服务器编程
- 数据库系统内核
- 操作系统
- 高性能计算
- 嵌入式开发
- 游戏引擎和图形引擎开发
- 虚拟机和容器化技术
- 网络协议栈与路由器
- 后端平台工具开发
- 编译器


## 课程大纲
### 1. 系统编程
- 系统调用

- TCP
- HTTP

### 3. 操作系统

- 并行优化

- DPDK

### 4. 工具
- ssh 远程登录
- git 版本管理
- vim 编辑器
- gcc 编译

- gdb 调试
- valgrind 内存泄露

### 5. 异步I/O
